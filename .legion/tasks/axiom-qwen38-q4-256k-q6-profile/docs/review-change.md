# 变更审查: Q4 256K 默认档与 Q6 高精度档

## 结论

PASS

## 阻塞项

无。

## 审查结果

- 变更限定于 Qwen 服务模块、任务证据、wiki 和用户明确要求删除的 Q5 本地模型工件。
- Q4 与 Q6 仍通过固定文件路径和固定 systemd unit 选择，未扩大 sudo-adjacent 控制面的输入范围。
- Q4 256K/Q8 由实测确认全 GPU 推理，长生成 107.91 tok/s，GPU SM 96-97%，CPU 约单核，修复了 Q5 的混合推理瓶颈。
- Q6 128K/Q4 fallback 已实际启动并健康，再次返回 Q4 后服务仍健康。
- Q5 配置、命令和文件均已移除；剩余 Q4/Q6 两档满足用户的默认性能与高精度路径。

## 安全视角

未触发。变更没有添加鉴权、信任边界、密钥处理或用户可控的高权限路径；模型选择面反而从三个固定目标缩小为两个。
