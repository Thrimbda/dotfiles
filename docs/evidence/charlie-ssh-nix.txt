N5. Current documentation lookup

Context7 resolved current OpenSSH documentation to:
  /openssh/openssh-portable

The fetched documentation confirmed the configuration semantics used here:
  restrict disables forwarding/session features by default;
  port-forwarding re-enables forwarding for the key;
  permitlisten restricts the remote listening address and port;
  MaxSessions=0 prevents shell/session channels but does not itself disable
  forwarding.

The final sshd Match block adds AllowTcpForwarding remote, so the per-key
port-forwarding allowance cannot be used for client-side local forwarding.
